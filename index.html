Key Insights

What the data tells us about AI-assisted code quality and duplication patterns.

💡

AI tools are not inherently duplicative

Five projects achieved 0% duplication despite being vibe-coded, proving quality depends on developer review practices, not just the tool. The cleanest projects include n8n-workflows-noz (2,556 lines), SC2SmoothBrainifier (1,309 lines), safe-vibe-coding (1,202 lines), vibe-check (1,008 lines), and vibe-security-skill (890 lines).

📄

Documentation duplication is an AI artifact

Markdown clones account for 11.1% of all duplication — far above typical human codebases. AI assistants frequently generate identical boilerplate in AGENTS.md, CLAUDE.md, and README templates across projects.

⚡

TypeScript dominates the clone landscape

With 43.7% of all clones in TypeScript files, the modern AI web stack (React + TypeScript) is the primary duplication vector. The boilerplate nature of type-heavy code contributes to this concentration.

📏

Large projects can manage duplication

cherry-studio (396K lines, 6.24%) and oh-my-claudecode (159K lines, 6.11%) demonstrate that project scale does not dictate duplication rate. Architecture and review discipline matter more than size.

Refactoring Recommendations

Specific strategies to reduce duplication in AI-assisted codebases.

01

Extract Shared Logic

Projects with >5% duplication should prioritize extracting repeated utility functions, hooks, and services into shared modules. This is the #1 improvement opportunity across all 46 projects.

02

Centralize Configuration

Many projects duplicate JSON, YAML, and CI configs. Use shared config packages (e.g., @company/eslint-config) or monorepo tooling to eliminate repeated configuration.

03

Build Component Libraries

UI-heavy projects show significant TSX/JSX duplication. A shared component library with prop-driven variants eliminates near-identical components generated by AI prompts.

04

Documentation Templates

Markdown duplication in AI projects is high. Use documentation generators (Docusaurus, VitePress) with template inheritance rather than copy-pasting README/AGENTS.md boilerplate.

05

CI Duplication Gates

Integrate jscpd into CI with a threshold (e.g., 5%). Block PRs exceeding the threshold. Pre-commit hooks catch issues before CI, preventing debt accumulation.

06

Code Review Focus

In vibe-coded projects, AI generates boilerplate with minor prompt variations. Reviews must specifically scan for near-duplicate blocks that can be unified into shared utilities.
