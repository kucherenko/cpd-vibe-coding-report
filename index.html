Nine charts derived from jscpd 4.2.0 analysis revealing clone distribution across formats, types, and project sizes.

01. Top Projects by Duplication %

Five projects exceed 15% duplication. frontend-slides leads at 42.71%; new project agent-skills shows 37.61% despite 22K lines.

02. Top Projects by Clone Count

void (1.2M lines, 5,312 clones) and oh-my-claudecode (531K lines, 2,247 clones) dominate absolute clone count. Both are large-scale IDEs.

03. Project Size vs. Duplication Rate

Scatter plot reveals project size alone does not predict duplication. Small projects like frontend-slides show extreme rates, while massive codebases like void (~1.3M) and refly (~310K) maintain ~6%.

04. Clone Distribution by Format

TypeScript leads at ~43% of clones, followed by TSX, JavaScript, Markdown, and Python. The dominance of the TS/JS ecosystem is clear.

05. Clone Distribution by Type

93%+ of clones are in actual source code. Config and documentation duplication are notable but secondary in AI-generated codebases.

06. Duplication Rate Distribution

Most projects (20) cluster in the 3-8% range. Only 6 exceed 10%, and 3 scored 0% duplication (perfect DRY scores).

07. Duplicated Lines by Format

TS/JS produce the most duplicated lines, but Markdown (documentation) is surprisingly high — an artifact of AI scaffolded README/AGENTS files.

08. Clone Type Breakdown

Top 15 projects show code duplication overwhelming other types. Config duplication only appears in large projects (cherry-studio, void).

Analysis

Key Insights

What the data reveals about AI-assisted code quality and duplication patterns.

💡

93.5% of projects have duplication

Out of 49 projects analyzed, 43 contain code clones. Only 3 (devin.cursorrules, jarvis-voice-assistant, lk_locator) scored 0%. This suggests vibe coding tools tend to produce repeated boilerplate.

📄

Documentation duplication is an AI artifact

AI assistants scaffold identical README/AGENTS.md/CLAUDE.md templates. Markdown clones account for a significant share, especially in tutorial/example repos like context-engineering-intro.

🔍

No cross-project clones found (with --skipLocal)

Using jscpd 4.2.0's cross-project detection (--skipLocal), zero identical blocks were found spanning different repositories. Vibe-coded projects may clone boilerplate from AI output, but they don't copy each other's unique code at the token level.

⚡

Large projects manage duplication well

void (1.3M lines, 6.60%), refly (310K lines, 4.42%), and cherry-studio (396K lines, 6.25%) keep rates moderate. Duplication is not a size problem — it's a review discipline problem.

🏢

Individual developers vs. organizations

High duplication appears across both types: individual projects (agent-skills @ 37.61%, frontend-slides @ 42.71%) and organizational ones (cofounder @ 25.32%, cockpit-tools @ 20.55%). Ownership does not predict duplication quality.

Refactoring Recommendations

Specific strategies to reduce duplication in AI-assisted codebases.

01

Extract Shared Logic

Projects with >5% duplication should extract repeated utility functions, hooks, and services into shared modules.

02

Centralize Configuration

Use shared config packages or monorepo tooling. Many projects duplicate JSON/YAML configs.

03

Build Component Libraries

UI-heavy projects show significant TSX/JSX duplication. A shared component library with props-driven variants eliminates near-identical components.

04

Documentation Templates

Use Docusaurus/VitePress with include macros rather than copy-pasting README/AGENTS.md boilerplate.

05

CI Duplication Gates

Integrate jscpd into CI/CD pipelines with a threshold (e.g., 5%). Block PRs exceeding the limit.

06

Code Review Focus

In vibe-coded projects, AI generates boilerplate with minor variations. Reviews must scan for near-duplicate blocks that can be unified.
